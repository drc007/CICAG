A repository to hold the initial scoping and outline for CICAG python material

The course for hosting as a Jupyter Book and is structured as follows:

- **1 Tools and setup:**
  - An intro to VS code and miniconda

- **2 Lets get coding!:**
  - Python teaching notebooks from basics up to functions

- **3 Chemistry relevant libaries:**
  - Use of RDKit, matplotlib and pandas

- **4 Lets code a project!:**
  - 4 exemplar coding projects with various degrees of guidance

- **CICAG_course_slides:**
  - Contains the slides to be delivered alongside the Jupyter book

- **User Contributions**
- More advanced notebooks that have been contributed

Other files:

- **myst-yml-builder.py:**
  - Creates the yml file for use in the Jupyter book
