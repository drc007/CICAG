# Welcome to the CICAG python course! ##

### A course designed for chemists writen by chemists.

By the of this course we want you to be to:

- Be setup and understand the tool required to code in Python

- Understand the language of coding and how to use resources effectively to help you with writing and learning code

- Implement workflows to help you with day to day tasks


The goal of this course is to, set you up with the tools, teach you how to go about coding and understand the terminology needed to code for yourself.

Course Structure

- Tools and setup 
    - VScode Overview- Integrated Development Environment
    - Miniforge Overview- Package Manager

- Key terminology and resources
    - Python basic terminology 
    - Coding resources
        - Using language models effectively
        - Self taught resources

- Lets get coding!
    - Basics - Objects, Data Types, Commenting, Data collections
    - Functions
    - Example code you will understand by the end of the workshop

- Chemistry relevant libaries - Pandas, RDKit, Matplotlib, Numpy
    - Data handling - Pandas 
    - Molecule Visualisation - RDKit
    - Data Visualisation - Matpltlib
    
- Lets code a project!
    - Example project and example code to practice the skill you have learnt
